# 地图识别的必填字段提示修正

日期：2026-10-24。接续 [GLM 兜底](book-map-atlas-fallback.md)。

## 问题与修改

旧提示中的 `Omit uncertain modern equivalents` 未说明应删除整个地点，可能被理解为只省略 `modernName` 或 `countryCode`。此前真实 DeepSeek 响应的四条地点记录恰好在这些必填字段上被严格校验拒绝；当时日志只有字段路径与错误类型，不能证明原始值具体为何，也不能断言提示歧义是唯一原因。

本次仅收紧共用识别提示：

- 明确七个顶层字段、每个地点的五个字段，以及字符串、数字、布尔值和数组类型。
- 无法确认现代地名或现今国家代码时，省略整个地点；不得保留缺字段的对象，也不得用猜测或占位符填充。
- 国家代码必须是现今 ISO 3166-1 alpha-2 的两位大写代码；地图年代与编号仍是字符串，缺失标题信息用空字符串。
- 仅 `bounds` 与 `imagePoint` 可以是 `null`；输出前检查完整性。
- 最多请求 24 个清晰可辨的城市；少于 24 个或空数组均合法，不要求凑数。上限直接复用代码常量。

维持既有 schema 校验、地名库坐标匹配、置信度阈值和 GLM 兜底。DeepSeek 与 GLM 使用同一输出约定，不新增解析分支或依赖。成功缓存继续复用 `v3`，线上验收通过“重新识别”绕过缓存，不清空其他用户的结果。

Prompt 不能保证所有输出始终符合约定；字段合法也不能证明 OCR、历史地名对应关系、区域范围或图内锚点正确。

## 验证

- Worker 类型检查通过；6 个测试文件、66 项测试全部通过。
- 地图测试 25 项通过，包含新增的必填字段为 null、必填字段缺失、国家代码格式不合要求时仍只调用一次 GLM 并缓存成功结果的回归用例。这些 mock 用例验证失败路径，不用来证明 prompt 有效。
- Wrangler 部署预检通过，前端静态资源无变化。
